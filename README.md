# WeatherLib

A library for the Deltarune fan-game engine Kristal that adds weather effects
to a Mod.

This maintenance fork is based on [MrFukuo/WeatherLib](https://github.com/MrFukuo/WeatherLib)
`v1.1.0`. It retains the original authorship and does not add a license where
the upstream repository did not provide one.
